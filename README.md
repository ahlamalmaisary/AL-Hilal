# BLUEVERSE — عالم الهلال
موقع جماهيري عربي متجاوب لنادي الهلال السعودي، يجمع الهوية السينمائية السابقة مع تجارب تفاعلية حديثة دون حذف الأقسام الأساسية.

## محتويات المشروع
- `index.html` — واجهة الموقع والأقسام الكاملة.
- `style.css` — الهوية البصرية، Responsive CSS، الحركة والتأثيرات.
- `app.js` — بيانات اللاعبين والمباريات، الفلاتر والبحث، متحف زمني، بطاقة مشجع، غرفة توقعات، و30 سؤالًا في اختبار هلاليتك.
- `assets/alhilal-mark.png` — الشعار المرفق من صاحبة المشروع.
- `api/quiz.php` — endpoint اختياري لحساب نتيجة الاختبار والتحقق منها على الخادم.
- `python/fixture_tools.py` — أداة Python لفحص وتحديث ملف بيانات المباريات.
- `data/fixtures.json` — بيانات مباريات قابلة للتحديث.
- `SOURCES.md` — مصادر معلومات وصور اللاعبين.

## التشغيل محلياً
يمكن فتح `index.html` مباشرة في المتصفح. لتشغيل PHP:
```bash
php -S localhost:8000
```
ثم افتح `http://localhost:8000`.

## التقنيات
HTML5 + CSS3 + JavaScript ES6، مع PHP endpoint وPython utility. لا توجد مكتبات JavaScript خارجية مطلوبة.

## ملاحظات
- اختبار هلاليتك يتكون من 30 سؤالًا مع تصحيح فوري ونتيجة من 30.
- أضيفت تجارب ليلة المباراة، المتحف الزمني، غرفة القيادة والتوقعات، بطاقة المشجع، وذاكرة اللحظات.
- بعض معلومات التشكيلة والمواعيد قابلة للتغيير ويجب مراجعة المصادر الرسمية قبل اعتمادها كمعلومة آنية.
- المشروع تصميم جماهيري غير رسمي ولا يمثل نادي الهلال أو يتحدث باسمه.
